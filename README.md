-*Sobre o projeto*-

O Beauty Universe é um site desenvolvido com o objetivo de apresentar o universo da maquiagem, seus dierentes estilos, produtos essesnciais e dicas de beleza.

O projeto busca proporcionar uma experiência visual agradável, deliada e intuitiva, utilizando uma identidade visual de tons rosa claro e explorar universos diferentes da maquiagm.

-*Objetivo*-

Desenvolver uma página web utilizando HTML, CSS e javaScript, aplicando coneitos de estruturação, etilização, responsividade, interatividade e validação de dados.

-*Tecnologias utilizadas*-

HTML5-Estrutura e organização do conteúdo
CSS3-Estilizão e adaptação para diferentes telas
JavaScript-Interatividade, validação de formulários e cálculos.

-*Funcionalidades*-
-Apresentação do universo da maquiagem.
-Seção com diferente estilos de maquiagem
